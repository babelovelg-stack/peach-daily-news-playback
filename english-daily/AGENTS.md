# 桃子英语每日课

本模块提供 Power Up 3 起步的词汇学习与经核对的原书伴读；当前云端入口为 `v2/`，旧版课程只用于已发送内容回看。

- 课程、语音脚本、答案和反馈一起维护；构建必须验证音频的文本与声音指纹、字节哈希。
- 使用 Node.js 24 和 Python 的 edge-tts 7.2.8；命令、发布与邮件状态流程见 README。
- 每天按上一次成功发送的课程序号推进。发送记录与新闻项目分开，保留发送前线上校验及不明确投递状态的人工核查门槛。
- 不记录孩子身份或上传作答。词汇插画、答案反馈和课程音频须内嵌；出版社原书可采用联网阅读器，但页面和邮件必须明确联网范围。
- 原书图片、文字、词汇/语法讲解和题目依据必须逐页核对；原书缺失时停止新版推送，不用原创故事或测试样本冒充原书。
- 自行查找原书时优先出版社资源，区分已找到目录、需登录阅读和已核对正文；在线阅读入口明确说明联网与登录条件，不能把官网可阅读当成可复制整本书的授权。
- 每课五个重点词、一段原书阅读、1–2道理解题，按25分钟以内配量；长书应分段，复习课明确不新增五词。
- 出版社公开样章模式只链接官方原页，保存已目视核对的页码与来源哈希，构建和发送前重新验证；不复制整页图片或全文，不将重点片段音频描述成整页同步朗读。
- 用户提供的原书明文、音频和学习密钥只在私有输入或临时构建目录中处理；公开仓库与站点只放加密阅读载荷，不得进入公开缓存、日志或工作流产物。
